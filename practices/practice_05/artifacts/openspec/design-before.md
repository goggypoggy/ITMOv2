# Design (до применения правила Mermaid)

## Context
Существующий `initLevelSwitcher` управляет активным уровнем и обновляет «Программу» и «Тарифы». Требуется добавить действие «Сброс» для программной установки уровня «Новичок» без изменений архитектуры.

## Goals / Non-Goals
- Реализовать сброс уровня к «Новичок». Сохранить доступность и одностраничность.
- Не менять данные и калькулятор времени.

## Decisions (до применения правила)
- Добавить кнопку `#level-reset` в зоне `#level-switcher`.
- Навесить обработчик клика: программно вызвать установку уровня «Новичок».

Примечание: диаграмма взаимодействия будет добавлена по правилу проекта в актуальной версии design (см. заархивированный design.md с Mermaid).
