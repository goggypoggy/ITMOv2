# UI Spec — Reset Level to Default (до согласования)

## Screens & Actions
- Controls: три таба уровней (Новичок, Средний, Продвинутый). Кнопка «Сброс» — размещение не согласовано (TBD: внутри `#level-switcher` или справа от блока).
- Action: нажатие «Сброс» возвращает активный уровень к базовому.

## States
- Активный таб выделен стилем; aria‑требования не финализированы (TBD: `aria-selected`, `tabindex`).
- После сброса обновляются блоки «Программа» и «Тарифы». Подтверждение aria‑live TBD.

## Errors
- Пользовательских ошибок не показываем. Повторные клики «Сброс» безопасны (без ошибок в консоли).

## Acceptance Criteria (черновик)
1) Нажатие «Сброс» делает активным базовый уровень и обновляет секции без перезагрузки.
2) Повторные клики не ломают состояние.
3) Кнопка не мешает навигации по табам.

## Out of Scope
- Сохранение выбора, изменение данных, взаимодействие с калькулятором.
