# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный: корректный вход и формат ответа | Есть diff, имеющий корректную структуру; размер ≤ 20000 символов; доступен POST /api/reviews | Отправить POST /api/reviews с этим diff | Ответ соответствует OUT-1: JSON со summary, risks (≤3) и checks; по QA-1 у каждого риска заполнены file, line, evidence | Ответ сервиса; парсер схемы OUT-1 |
| Негативный: таймаут внешнего LLM | Смоделирована задержка внешнего LLM > 10 с | Выполнить запрос, ожидая ответ | Время ожидания ответа превышает 10 с: контролируемая ошибка по правилу REL-1 (таймаут 10 с) | Ответ сервиса; логи статуса |
| Граничный: превышение лимита размера | Размер diff > 20000 символов | Отправить POST /api/reviews с diff | HTTP 413 по правилу API-1 (лимит 20000 символов) | Ответ сервиса |
| Позитивный: удаление секретов перед LLM | diff содержит тестовый токен/секрет (например, TOKEN_TEST) | Отправить POST /api/reviews с таким diff | Перед отправкой во внешний LLM секреты удалены/заменены на [REDACTED] по SEC-1 | Инструментальная проверка исходящего запроса к LLM в тестовом окружении |
| Позитивный: отсутствие логирования содержимого | Включено логирование request_id/длительности/статуса | Выполнить POST /api/reviews | В логах только request_id, длительность и статус; diff/ответ не логируются по OBS-1 | Логи сервиса |
| Позитивный: отсутствие внешних действий | Доступ к внешним системам (GitHub) отключён/заглушен | Выполнить POST /api/reviews | Сервис не выполняет approve/merge/коммиты; даёт только советы по SCOPE-1 | Отсутствие внешних вызовов; состав ответа |
| Негативный: риск без evidence | Внешний LLM возвращает риск без поля evidence | Выполнить POST /api/reviews | Риски без evidence не включены в ответ по QA-1; возвращён контролируемый результат | Ответ сервиса |
| Негативный: число рисков > 3 | Внешний LLM возвращает более 3 рисков | Выполнить POST /api/reviews | Ответ приводит массив рисков к ограничению OUT-1 (≤3) или отклоняется контролируемой ошибкой | Ответ сервиса; статус |
