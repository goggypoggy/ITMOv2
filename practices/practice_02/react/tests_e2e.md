# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный: корректный вход и формат ответа | Есть unified diff одного PR; размер ≤ 20000 символов; доступен POST /api/reviews | Отправить POST /api/reviews с diff | Ответ соответствует OUT-1: JSON со summary, risks (≤3) и checks; по QA-1 у каждого риска заполнены file, line, evidence | Ответ сервиса; парсер схемы OUT-1 |
| Негативный: таймаут внешнего LLM | Смоделирована задержка внешнего LLM > 10 с | Выполнить запрос | Контролируемая ошибка по REL-1, без 5xx; время ожидания ≤ 10 с | Ответ сервиса; логи статуса |
| Граничный: превышение лимита размера | Размер diff > 20000 символов | Отправить POST /api/reviews с diff | HTTP 413 по API-1 | Ответ сервиса |
| Позитивный: удаление секретов перед LLM | diff содержит тестовый секрет (token) | Отправить POST /api/reviews (LLM замокан) | Перед запросом к внешнему LLM секреты удалены/заменены на [REDACTED] по SEC-1 | Перехват исходящего запроса к мок‑LLM; отсутствие секретов |
| Позитивный: отсутствие логирования содержимого | Включено логирование request_id/длительности/статуса | Выполнить POST /api/reviews | В логах нет diff/ответа; только request_id, длительность и статус по OBS-1 | Логи сервиса |
| Позитивный: отсутствие внешних действий | Доступ к внешним системам (GitHub) отключён/заглушен | Выполнить POST /api/reviews | Сервис не выполняет approve/merge/коммиты; даёт только советы (SCOPE-1) | Отсутствие внешних вызовов; состав ответа |
| Негативный: риск без evidence | Внешний LLM возвращает риск без evidence | Выполнить POST /api/reviews | Риски без evidence не включены (QA-1); структура ответа валидна | Ответ сервиса |
| Негативный: число рисков > 3 | Внешний LLM возвращает более 3 рисков | Выполнить POST /api/reviews | Итоговый массив рисков ≤ 3 (OUT-1) | Ответ сервиса |
