# Демо сценарий — Reset Level to Default

1. Запуск локально
- Перейти в каталог: `cd practices/practice_04`
- Запустить сервер: `npx --yes serve -l 8080 .`
- Открыть в браузере: http://localhost:8080/

2. Сценарий «основной»
- В «Выбор уровня» нажать «Средний».
- Нажать «Сброс».
- Ожидание: активным станет «Новичок», обновятся «Программа» и «Тарифы».

3. Сценарий «граница»
- При активном «Новичок» нажать «Сброс» дважды.
- Ожидание: состояние не меняется, ошибок в консоли нет.

4. Автотесты (опционально)
- Из `practices/practice_04`: `npm test` (поднимет webServer автоматически).
- Ожидание: 4 passed (см. practices/practice_05/artifacts/tests-last-run.txt).
