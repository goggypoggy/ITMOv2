## Master Prompt v1

### 1. Цель и роль

- Цель: просимулировать SDLC-цикл, опираясь на данные из PR.
- Роль AI: аналитик, продакт-менеджер, разработчик, тестер и проджект-менеджер.

### 2. Входы и источники

- Обязательный вход: TRAINING_PR.diff
- Разрешённые файлы и источники: разрешена работа с файлами из директория practices/practice_01: adr.md, analysis.md, context.md, problem.md, product_management.md, project_management.md, prompts.md, tests_e2e.md, tests_integration.md, tests_load.md, tests_unit.md

### 3. Задача и артефакты

- Что сделать: Для файлов adr.md, analysis.md, context.md, problem.md, product_management.md, project_management.md, tests_e2e.md, tests_integration.md, tests_load.md, tests_unit.md необходимо выполнить следующие шаги: 1) проанализировать их структуру; 2) установить, какой член команды должен был бы работать с этим файлом; 3) заполнить файл данными так, как будто бы это делал член команды; 4) в каждом файле есть сноска «Как использовали AI»: её нужно заполнить и сослаться на то, какие действия были совершены над файлом в результате этого промпта. В файле prompts.md по предоставленным пунктам расписать информацию о запуске этого промпта.
- Что вернуть: заполненные артефакты (перечисленные файлы) и запись о запуске в prompts.md.

### 4. Формат результата

- Формат: заполненные markdown‑файлы из списка разрешённых артефактов; в каждом файле заполнена сноска «Как использовали AI». В prompts.md добавлена запись о запуске.
- Ограничения объёма: каждый артефакт должен в конечном итоге содержать примерно 15000 символов, не более 20000 символов.

### 5. Полномочия и запреты

- Разрешено: менять файлы, перечисленные как «разрешённые файлы и источники».
- Запрещено: менять любые файлы, не перечисленные как «разрешённые файлы и источники», выполнять любые действия, связанные с GitHub.

### 6. Рабочий процесс и остановка

- Шаги: для каждого файла выполнить шаги 1–4 из раздела «Что сделать».
- Когда остановиться: после выполнения шагов для всех файлов и внесения записи о запуске в prompts.md.

### 7. Проверки и evidence

- Проверка: артефакты заполнены; в каждом файле заполнена сноска «Как использовали AI»; в prompts.md есть запись о запуске с перечислением изменённых файлов; соблюдены ограничения объёма.

### 8. Definition of Done

- Задача закончена, когда: все артефакты — то есть файлы, перечисленные как «разрешённые файлы и источники» — заполнены данными.

## Сравнение двух запусков

| Проверка | Zero-shot | С master prompt | Вывод команды |
|---|---|---|---|
| Есть ссылка на файл или строку | Частично | Да, у каждого риска | Улучшение по evidence |
| Вывод подтверждён diff или правилом | Неполно | Да (diff/правила) | Соответствие QA-1 |
| Соблюдены границы AI | Нарушены (советы вне scope) | Соблюдены | Без рекомендаций вне scope |
| Есть воспроизводимая проверка | Нет | Да | Checks указывают конкретные шаги |
