# Logic Spec — Reset Level to Default (до согласования)

## Data & Interfaces
- Новые данные не вводятся. Базовый уровень — «Новичок» (подтвердить у PO).
- Публичное поведение: обработчик «Сброс» вызывает программный выбор уровня (API TBD).

## Algorithm / Rules (черновик)
1) На действие «Сброс» выбрать базовый уровень.
2) Обновить активное состояние табов и перерендерить блоки «Программа» и «Тарифы».
3) Если базовый уже выбран — повторный вызов идемпотентен.

## Validation & Errors
